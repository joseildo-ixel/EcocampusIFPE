# EcoCampusIFPE

Sistema web para registrar, acompanhar e organizar o descarte de lixo eletrônico no campus do IFPE.

## Visão geral

O EcoCampusIFPE é uma plataforma para que alunos, professores e trabalhadores do campus consigam registrar itens eletrônicos descartados, acompanhar o status da coleta e permitir que a instituição organize a destinação correta desses materiais.

A ideia central é transformar o processo manual em um fluxo digital, com cadastro, classificação, agendamento de coleta e acompanhamento das ações de descarte.

## Objetivo

Facilitar o registro e o gerenciamento de resíduos eletrônicos no campus, reduzindo descarte inadequado, organizando a logística de coleta e gerando dados para decisões internas.

## Papel principal da solução

- Registrar itens eletrônicos enviados para descarte
- Classificar tipo de material e estado de uso
- Agendar coleta ou encaminhamento para descarte adequado
- Consultar histórico e status das solicitações
- Monitorar dados por setor, categoria e volume

## Stack sugerida

- Backend: NestJS + TypeScript
- Frontend: React + TypeScript + Vite
- Banco de dados: PostgreSQL
- Hospedagem: PaaS gratuita
